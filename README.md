## 👋 About me

I’m MH Joy, a builder focused on practical software: AI-powered desktop tools, automation, network utilities, API infrastructure, and self-hosted systems.

I like the whole journey—from a rough idea and a stubborn bug to a tested tool that somebody can actually use.

> **Build principle:** make it work → make it right → make it fast.

## 🔧 What I build

| Area | What that looks like |
| --- | --- |
| 🎙️ AI desktop tools | Voice, audio, and multimodal assistants that stay useful while you work |
| ⚡ Systems utilities | Windows and Rust tools that observe, control, or optimize the machine |
| 🔌 AI infrastructure | Gateways, provider routing, compatibility layers, and operational tooling |
| 🤖 Automation | Telegram, Discord, email, browser, and workflow automation |
| 🌐 Product engineering | React/Next.js experiences, storefronts, APIs, and internal tools |
| 🐳 Operations | Docker, Nginx, Cloudflare, Linux, VPS deployment, and monitoring |
